# Exercícios Android Studio — Java

Este repositório contém 7 exercícios em Android Studio usando Java, TextInputLayout/TextInputEditText, `findViewById`, botões e saída no Logcat.

## Projetos

1. Pedido de Lanche
2. Cadastro de Pet
3. Reserva de Sala
4. Tela de Login
5. Inscrição em Evento
6. Cadastro de Produto
7. Recuperar Senha

Cada pasta contém os principais arquivos do exercício: `MainActivity.java` e `activity_main.xml`.
